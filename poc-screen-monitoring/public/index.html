POC Isolated Environment
Tujuan & Ruang Lingkup Prototipe (Phase 1 POC)

Prototipe ini membuktikan kelayakan teknis memantau tampilan layar tab WhatsApp Web seluruh Sales secara langsung (Live) dalam satu layar komputer Admin tanpa biaya langganan API berbayar (Rp 0), tanpa bot tidak resmi yang berisiko banned, dan tanpa mengubah database produksi CRM Captain Konveksi.

✓ Teknologi: Browser Screen Capture (getDisplayMedia) + WebRTC P2P + WebSocket Signaling
✓ Biaya Langganan: Rp 0 (Free Open Web Standards)
✓ Keamanan: Audio/Mikrofon dinonaktifkan (Video Tab Only)

Arsitektur & Konfigurasi Jaringan (STUN / TURN)

1. Koneksi Jaringan Kantor (Local LAN / Wi-Fi Sama): WebRTC langsung terhubung P2P secara lokal tanpa keluar ke internet publik, menghasilkan latensi sangat rendah (< 20ms) dan kualitas gambar jernih.

2. Koneksi Internet Lintas Lokasi (STUN): Menggunakan Google STUN (stun:stun.l.google.com:19302) untuk mendeteksi IP publik jika Sales dan Admin bekerja dari tempat berbeda (misal Sales WFH dan Admin di kantor).

3. Relai Simetrik (TURN): Jika kedua pihak berada di balik firewall perusahaan atau NAT simetrik yang ketat, TURN relay server (seperti Coturn gratis open-source atau Metered) dapat diaktifkan sebagai jalur cadangan agar koneksi tidak pernah gagal.

4. Optimasi Bandwidth: Tab teks seperti WhatsApp Web hanya membutuhkan 10 FPS pada resolusi 720p. Konsumsi bandwidth hanya sekitar 250 Kbps per Sales, sehingga Admin dapat memantau 10 Sales sekaligus dengan bandwidth internet ~2.5 Mbps saja.
